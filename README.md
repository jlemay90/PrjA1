# PrjA1

PrjA1 is an evidence-driven repository audit and improvement workspace.

## Purpose
Systematically map a target codebase, discover and verify defects, prioritize findings, implement minimal fixes, validate changes, and preserve an audit trail.

## Core rule
Never present a suspected issue as a confirmed bug. Findings are classified as VERIFIED, REPRODUCIBLE, PROBABLE, or UNVERIFIED and should be backed by executable evidence whenever possible.

## Workflow
Map → Discover → Verify → Prioritize → Fix → Test → Document → Improve

See `docs/AUDIT_PLAN.md` for the operating process and `docs/FINDINGS.md` for the findings ledger.
